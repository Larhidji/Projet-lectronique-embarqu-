# Projet-electronique-embarqué-
Ce projet me permet d'allumer une led avec arduino uno, ce projet d'initiation aux systèmes embarqués permet de mettre en main la carte microcontrôleur Arduino Uno pour programmer et piloter des composants électroniques.
Ce projet montre comment concevoir un circuit simple permettant d'allumer et controler l'état d'une Led à l'aide d'un script e C++ sur l'IDE arduino. les différents materiels que j'ai utilisé sont:
- une carte arduino uno
- une led
- une reistance
- fils jumpers
- un breadboard                                                                                                                                                                             # Circuit et montage                                                                                                                                                                       - connectez l'anode de la led a la brochure numérique 13 de l'arduino                                                                                                                      -Intercalez une resistance de 220 ohm en série pour éviter de griller la Led                                                                                                               -connectez la cathode a la broche GND de l'arduino
